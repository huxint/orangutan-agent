### Design Intent

`core::Time` is the canonical absolute-time type that crosses library
boundaries. Future memory `Record` fields (`created_at`, `updated_at`,
`last_read_at`), audit log rows, and the typed evolution of
`SessionRepository`'s timestamp strings all need *one* representation rather
than ad-hoc chrono uses at every callsite.

The formatter pins the wire shape explicitly with `std::format`'s integer
fields instead of chrono format specifiers. The benchmark documents that this
deterministic format costs ~2× a `{:%FT%T}Z` chrono format call (~339 ns vs.
~174 ns on this host), but the explicit form pins millisecond precision and
zero-padded year fields regardless of standard-library evolution. The strict
parser exists for the same reason: the system writes timestamps and reads
them back; loose acceptance leaks bug-shaped variation into storage rows.
