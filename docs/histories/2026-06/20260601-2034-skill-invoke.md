### Design Intent

This closes the smallest useful skill execution path without changing prompt-cache
prefix semantics. `oran-tool` owns JSON parsing, capability declaration,
permission/audit/hook/output-cap dispatch, and model-repairable runtime errors;
bootstrap owns lookup against the already-loaded workspace skill snapshot so
`oran-tool` does not depend on `oran-skill`. The implementation deliberately avoids
mid-turn disk reads and leaves watcher hot-reload as the next prompt-runtime slice.
