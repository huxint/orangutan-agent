| 2026-05-16 | permission-materialize | `oran-permission` now ships `permission::materialize(Mode, const config::PermissionsConfig& global, const config::PermissionsConfig& per_agent) -> RuleSet`, the three-layer merge that combines built-in defaults with global `config.permissions` and per-agent `agents.<name>.permissions` overlays. The design-doc three-layer rule pipeline is end-to-end live: future bootstrap code can hand any agent's runtime evaluator a fully-merged `RuleSet`. `xmake run orangutan` still reports slice 7. | New `include/oran/permission/materialize.hpp` and `permission::materialize`. Layer order is defaults → global → per-agent; the runtime evaluator's deny → allow → ask precedence is unchanged, so an explicit `deny` in any layer outranks an `allow` in any other layer (matching the design-doc guarantee). A two-argument overload uses an empty per-agent overlay for call sites that haven't selected an agent. `oran-permission` now depends on `oran-config` (legal — config sits below permission in the module-boundary layering); the umbrella `<oran/permission.hpp>` re-exports the new header. `tests/permission` grows to 30 cases / 114 assertions (empty merge == defaults, layer order preserved, verdict mapping one-to-one, capability scope preserved, deny in any layer outranks allow in any other layer, intra-layer order preserved, two-argument overload behavior); `bench/permission` adds a three-scenario block — `materialize_defaults_only` (~122 ns), `materialize_with_global` (~230 ns over 8 global rules), `materialize_with_global_and_agent` (~257 ns over 8 global + 2 overlay). re2 input regex, HMAC approvals, and audit logging remain downstream. | [history](../histories/2026-05/20260516-2305-oran-permission-materialize.md) |

Validation: missing `tool_pattern` errors; empty `tool_pattern` errors; unknown capability spelling errors; non-object rule entry / wrong array type errors; unknown verdict key + unknown rule field + unknown agent field warn (loose) or fail (strict). `tests/config` grows to 12 cases / 120 assertions; `bench/config` adds an empty-vs-typed permissions parse A/B (~879 ns vs. ~18.4 µs over 16 rules + one agent overlay). | [history](../histories/2026-05/20260516-2210-oran-config-permissions.md) |
